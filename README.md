# 🚗 Car Price Prediction

A Machine Learning project that predicts the selling price of used cars based on different car features.

## 📌 Project Overview

This project analyzes car-related data and uses Machine Learning techniques to predict car prices.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Flask
- Jupyter Notebook

## 📂 Project Files

- `car_price_analysis.ipynb` – Data analysis and model development
- `car_data.csv` – Dataset
- `artifacts.joblib` – Trained model artifacts
- `app.py` – Flask application

## 🎯 Objective

To build a Machine Learning model that can estimate the price of a used car based on its features and specifications.
